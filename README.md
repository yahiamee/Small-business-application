# Small Business Learning Application

An Android-oriented educational application built with Ionic and Cordova to support learning content related to small-business projects.

## Overview

This repository is an early mobile-development project that demonstrates a hybrid-app approach using Ionic/Cordova and a web technology toolchain.

## Technology

- Ionic
- Cordova
- Android
- Gulp
- HTML / CSS / JavaScript

## Purpose

The application was created as an educational tool focused on small-business learning and project concepts.
